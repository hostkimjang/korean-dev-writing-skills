# trace-slice

`trace-slice`는 로컬 JSON Lines 로그 파일에서 지정한 최소 심각도 이상의 항목을 골라 내는 CLI입니다. 로그를 네트워크로 전송하지 않습니다. 이 문서는 **0.4.2** 버전을 기준으로 합니다.

## 설치

프로젝트에서 선언한 Python 요구 버전은 **3.10 이상**입니다. 설치와 기본 동작은 **Ubuntu 22.04의 Python 3.11**에서 확인했으며, 다른 운영체제에서의 검증 기록은 없습니다.

다음 명령으로 0.4.2 버전을 설치합니다.

```bash
python -m pip install trace-slice==0.4.2
```

설치 후 도움말을 확인합니다.

```bash
trace-slice --help
```

## 첫 실행: 오류 로그 확인하기

입력에는 로컬 JSON Lines 파일 경로를 지정합니다. 각 정상 로그 행에는 `level` 필드가 있습니다. 아래 명령의 `./logs/api.jsonl`은 예제 경로이므로, 확인할 로그 파일 경로에 맞게 바꿔 실행하세요.

```bash
trace-slice ./logs/api.jsonl --level error
```

이 명령은 `error` 항목을 표준 출력으로 내보냅니다.

## 사용 형식과 주요 옵션

```text
trace-slice INPUT [--level LEVEL] [--output PATH]
```

| 인수·옵션 | 설명 | 기본 동작 |
| --- | --- | --- |
| `INPUT` | 읽을 로컬 JSON Lines 파일 경로입니다. 필수 위치 인수입니다. | 생략할 수 없습니다. |
| `--level LEVEL` | 지정한 값과 그보다 높은 심각도의 항목을 출력합니다. 허용 값은 `debug`, `info`, `warn`, `error`입니다. | `info` |
| `--output PATH` | 결과를 `PATH`에 지정한 파일에 씁니다. **파일이 이미 있으면 덮어씁니다.** | 생략하면 표준 출력으로 내보냅니다. |

심각도는 `debug`, `info`, `warn`, `error` 순서로 높아집니다. 예를 들어 `--level warn`을 지정하면 `warn`과 `error` 항목을 출력하고, `--level`을 생략하면 `info`, `warn`, `error` 항목을 출력합니다.

## 사용 중 알아둘 점

- **JSON 구문이 잘못된 행**은 건너뛰고, 건너뛴 행 수를 표준 오류로 알립니다. 잘못된 JSON 행이 있다는 이유만으로 실행이 실패하지는 않습니다.
- **입력 파일을 읽을 수 없으면** 오류를 표준 오류로 알리고 종료 코드 `2`로 끝납니다.
- **0.4.2에는 실행 중 늘어나는 로그를 계속 따라가는 기능과 날짜 범위를 지정하는 옵션이 없습니다.**
