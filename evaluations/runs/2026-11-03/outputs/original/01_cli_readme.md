# trace-slice

trace-slice는 로컬 JSON Lines 로그 파일에서 지정한 최소 심각도 이상의 항목을 골라 내는 CLI입니다. 로그를 네트워크로 전송하지 않으며, 결과를 터미널에 표시하거나 파일로 저장합니다.

이 문서는 **0.4.2** 기준입니다.

## 실행 환경

- **Python 요구 버전**: 3.10 이상
- **설치와 기본 동작을 확인한 환경**: Ubuntu 22.04, Python 3.11
- **다른 운영체제**: 검증 기록 없음

## 설치 및 첫 실행

### 1. 설치하고 도움말 확인하기

다음 명령으로 0.4.2를 설치합니다.

```bash
python -m pip install trace-slice==0.4.2
```

설치 후 도움말을 실행해 명령을 사용할 준비가 되었는지 확인합니다.

```bash
trace-slice --help
```

터미널에 도움말이 표시되면 다음 단계로 진행합니다.

### 2. 로그 파일 준비하기

확인할 로컬 JSON Lines 파일을 준비합니다. JSON Lines는 한 줄에 JSON 데이터 하나를 담는 형식입니다. 각 정상 로그 행에는 심각도를 나타내는 `level` 필드가 있어야 합니다.

이 문서에서는 `./logs/api.jsonl`을 예제 경로로 사용합니다. 명령을 실행하는 디렉터리에 해당 파일이 있는지 확인하세요. 파일이 다른 위치에 있다면 명령의 입력 경로를 실제 파일 경로로 바꿉니다.

### 3. 오류 항목 확인하기

`--level error`를 지정하면 입력 파일에서 `error` 항목을 골라 표준 출력으로 내보냅니다.

```bash
trace-slice ./logs/api.jsonl --level error
```

입력 로그에 `error` 항목이 있으면 해당 항목이 터미널에 표시됩니다.

## 사용 형식과 옵션

```text
trace-slice INPUT [--level LEVEL] [--output PATH]
```

| 인수·옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `INPUT` | 필수 | 읽을 로컬 JSON Lines 파일 경로 |
| `--level LEVEL` | `info` | 출력할 최소 심각도. `debug`, `info`, `warn`, `error` 허용 |
| `--output PATH` | 표준 출력 | 결과를 저장할 파일 경로. 기존 파일이 있으면 덮어씀 |

심각도는 `debug` → `info` → `warn` → `error` 순으로 높아집니다. 지정한 수준과 그보다 높은 수준의 항목을 출력합니다.

| `--level` 값 | 출력하는 로그 수준 |
| --- | --- |
| `debug` | `debug`, `info`, `warn`, `error` |
| `info` | `info`, `warn`, `error` |
| `warn` | `warn`, `error` |
| `error` | `error` |

## 자주 쓰는 명령

### info 이상 확인하기

`--level`을 생략하면 기본값인 `info`를 적용합니다.

```bash
trace-slice ./logs/api.jsonl
```

### 경고와 오류 확인하기

`warn`을 지정하면 `warn`과 `error` 항목을 출력합니다.

```bash
trace-slice ./logs/api.jsonl --level warn
```

### 오류 항목을 파일로 저장하기

`--output`으로 저장할 경로를 지정합니다. 다음 명령은 `error` 항목을 현재 디렉터리의 `errors.jsonl`에 저장합니다. **파일이 이미 있으면 덮어쓰므로 실행 전에 경로를 확인하세요.**

```bash
trace-slice ./logs/api.jsonl --level error --output ./errors.jsonl
```

## 입력 오류 처리

| 상황 | 처리 방식 |
| --- | --- |
| JSON 구문이 잘못된 행이 있음 | 해당 행을 건너뛰고 건너뛴 행 수를 표준 오류로 알립니다. 이 이유만으로 실행이 실패하지는 않습니다. |
| `INPUT` 파일을 읽을 수 없음 | 오류를 표준 오류로 알리고 종료 코드 `2`로 끝납니다. 입력 경로와 읽기 권한을 확인하세요. |

결과 로그와 오류 안내는 출력 경로가 다릅니다. `--output`을 생략하면 결과 로그는 표준 출력으로, 건너뛴 행 수와 읽기 오류는 표준 오류로 나갑니다.

## 사용 중 알아둘 점

- **파일 덮어쓰기**: `--output`은 기존 파일 내용을 덮어씁니다. 보관할 파일과 다른 경로를 지정하세요.
- **실시간 추적 미지원**: 0.4.2에는 실행 중 늘어나는 로그를 계속 따라가는 기능이 없습니다.
- **날짜 범위 지정 미지원**: 0.4.2에는 날짜 범위를 지정하는 옵션이 없습니다.
