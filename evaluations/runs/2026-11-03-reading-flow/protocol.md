# 읽기 흐름 보강의 소규모 사용 점검

실행일: 2026-11-03. 긴 온보딩 문서와 짧은 조사 PR을 각각 스킬 미적용·v0.2.1·v0.3.0 조건에서 한 번씩 생성한다. 총 6개 출력으로 새 지침이 적용되는 모습과 의미 보존, 짧은 문서의 과잉 구성을 살핀다. 실제 독자의 이해·기억·피로를 측정하는 실험이나 기존 20점 평가의 연장이 아니다.

## 생성 전 고정 사항

- 별도 작성자가 기존 스킬과 출력·채점 결과를 읽지 않고 공개 가능한 가상 사례 두 개를 준비했다. 사례 작성 요청에는 긴 서비스 온보딩과 짧은 미확정 원인 조사 PR이라는 용도와 조건 보존 요구가 포함됐다. 외부 사전 등록이나 독립된 대규모 표본 설계가 아니다.
- 원자료, 공통 입력, 두 스킬의 파일 해시를 `manifest.json`에 기록한다. 생성에는 공통 입력의 독자·목적·요청·사실 메모만 제공한다. 확인 질문과 정답, 필수 보존 항목은 전달하지 않는다.
- 각 사례·조건은 같은 상속 모델의 새 컨텍스트에서 작성한다. 스킬 조건에는 지정한 스킬 폴더만 추가한다. 공통 플랫폼 지침은 미적용 조건에도 적용된다.
- 출력은 한 번 생성하고 후편집하지 않는다. 도구 실패로 결과가 없는 경우만 같은 요청을 재시도하고 이유를 남긴다. 결과가 기대와 다르다는 이유로 교체하지 않는다.

## 확인할 내용

원자료와 출력을 대조해 조건·예외·식별자·미확정 사항·검증 상태의 변화를 확인한다. 긴 문서는 전체 관계, 용어와 지시 대상, 서로 참조하는 정보의 위치, 필요한 재정리를 살핀다. 짧은 PR은 요청한 분량과 용도에 맞는지, 불필요한 목차·개요·요약이 추가됐는지 확인한다.

독립 검토자는 조건을 가린 출력과 원자료로 사실 보존과 구조의 장단점을 기록한다. 표시 순서와 조건 대응표는 검토 완료 뒤 공개한다. 점수 합계나 길이 감소 목표를 만들지 않으며, 더 길어진 결과·차이가 작은 결과·불리한 결과도 기록한다. 검토자가 느낀 가독성은 실제 독자의 이해도나 피로 측정값으로 표현하지 않는다.

확인 질문은 핵심 관계와 세부 조건을 구분하는 데 사용한다. 원자료를 함께 본 모델의 답변을 순수한 독해·기억 시험으로 간주하지 않는다. 실제 독자의 읽기 시간, 지연 회상, 정보 재탐색 시간, 주관적 부담은 이번 점검 범위 밖이다.

## 기록과 보고

원자료·입력·출력·익명 대응표·검토 기록과 해시를 이 디렉터리에 보존한다. 같은 모델 계열과 단회 생성, 적은 가상 사례라는 한계를 표시한다. 기존 `2026-11-03` 실행의 출력과 점수는 수정하지 않는다. 사람 대상 효과 검증과 추가 반복 생성은 별도 실행으로 계획한다.
