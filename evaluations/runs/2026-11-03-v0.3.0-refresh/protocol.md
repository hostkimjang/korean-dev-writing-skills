# 배포된 v0.3.0으로 기존 비교 갱신

실행일: 2026-11-03. 기존 여섯 사례와 읽기 흐름 점검 두 사례의 입력으로 현재 배포된 스킬 적용 문서 여덟 개를 새로 작성한다. 스킬은 공개 커밋 `372622959b7561427b111b4d1f528ec80239b3df`의 여섯 파일과 정확히 같은 바이트를 사용하며 이번 실행 중 수정하지 않는다.

## 비교 조건

- 미적용 원문과 이전 적용 원문은 과거 실행에서 그대로 가져온다. 이번에 다시 생성한 것은 최신 적용 조건의 여덟 문서다. 모든 조건을 동시에 새로 생성한 실험이 아니다.
- 기존 여섯 사례는 미적용·v0.2.0·현재 v0.3.0, 읽기 흐름 두 사례는 미적용·v0.2.1·현재 v0.3.0을 비교한다. 직전 v0.3.0 초안 생성본과 검토 기록도 과거 실행 디렉터리에 남긴다.
- 입력·원자료·기존 출력·배포 스킬의 해시를 생성 전에 기록한다. 입력 복사본은 기존 입력과 바이트 단위로 동일하다.
- 현재 출력은 사례마다 별도의 새 컨텍스트에서 한 번 작성한다. 생성자에는 공통 입력과 동결한 스킬 폴더만 제공한다. 이전 출력, 평가 기준, 정답, 개선 목표, 검토 결과는 제공하지 않는다.
- 같은 세션 계열 모델을 상속하며 정확한 배포 식별자와 샘플링 설정은 노출되지 않는다. 예전 생성과 현재 생성의 시점·플랫폼 차이 및 단회 생성의 변동을 스킬 효과에서 분리할 수 없다.
- 출력은 후편집하지 않는다. 결과가 아쉽다는 이유로 재생성하지 않는다. 도구 실패로 출력 자체가 없을 때만 재시도하고 이유를 기록한다.

## 검토와 게시

출력을 고정한 뒤 사례별 표시 순서와 라벨을 무작위로 부여한다. 별도의 새 컨텍스트 검토자는 원자료와 익명 문서만 읽고 필수 사실·조건·미확정 상태 보존, 구조·문장 연결·탐색·반복의 장단점을 근거 구절과 함께 기록한다. 검토가 끝난 뒤 조건 대응표를 공개한다.

이번 갱신에서는 새 20점 합계나 이전 점수와의 수치 차이를 만들지 않는다. 이전 v0.2.0 점수와 원문은 역사적 기록으로 유지하며 현재 배포본의 점수로 표시하지 않는다. 길이는 공백·개행·Markdown 문법·마지막 개행을 포함한 Unicode 문자 수로 표시한다. 길이 감소 자체를 개선으로 판정하지 않는다.
