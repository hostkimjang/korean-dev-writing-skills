# 단비함 썸네일 작업기: 기록 순서 변경과 검증 상태

가상의 단비함 썸네일 작업기에서 변경 전 통합 환경의 예제 20건은 운영 화면상 모두 완료였지만 갤러리 카드 3개는 비어 있었다. 완료 집계는 큐 종료만 세며 파일 존재와 해독 여부는 검사하지 않는다.

파일 저장 완료 전에 결과 메타데이터가 기록되는 순서를 원인으로 의심하지만 인과는 미확인이다. 로컬에서 저장 함수의 성공 반환 뒤 메타데이터를 기록하도록 순서 한 곳만 바꿨으며 배포하지 않았다.

저장 함수 대역을 쓴 단위 검사 2건이 통과해 성공 반환 뒤에만 기록이 호출되고 실패 시에는 호출되지 않음을 확인했다. 실제 업로드·해독 검사는 아니며, 검증용 저장소의 업로드 자격 증명이 없어 예제 20건 재처리와 이미지 해독 검증은 못 했다. 빈 카드 해소 여부는 아직 모른다.
