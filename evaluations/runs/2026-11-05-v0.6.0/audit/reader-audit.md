# 완성 예시 독자 경험 검토

## 결론과 검토 범위

새 사실 오류로 확정할 만한 문제는 찾지 못했다. 아래 한 건은 진단 로그만 추가한 PR에서 검증 대상이 모호해지는 표현을 바로잡는 국소 교정이다. 수정량을 늘리기 위해 반복이나 형식 차이를 결함으로 분류하지 않았다.

완성 본문 10개를 읽었고, 01~08은 지정된 원자료의 요청·사실 메모와 대조했다. 09~10은 본문을 읽었으나 원자료 대조를 완료하지 않았다. 작업 중단 요청에 따라 추가 탐색 없이 현재 근거만 기록한다. 과거 리뷰와 저장소의 현재 SKILL.md는 검토하지 않았다.

## 1. 관측용 PR의 마지막 문장에서 무엇을 검증하지 못했는지 명시

- **대상:** `docs/examples/08_short_log_pr.md`, 마지막 문단
- **분류:** 검증 대상의 모호함. 사실 오류 판정은 아님.
- **원자료:** `evaluations/runs/2026-11-03-reading-flow/source/short-pr.json`, S03·S05·S07

### 본문 인용

> 동작은 유지합니다.

> 로컬 합성 요청 환경이 준비되지 않아 테스트와 변경 후 로그 수집을 못 해 가설·변경 동작도 검증하지 못했습니다.

### 독자가 걸리는 지점

앞에서는 기존 동작을 유지한다고 했는데 마지막에는 ‘변경 동작’을 검증하지 못했다고 한다. 이 표현이 추가한 진단 로그의 출력을 뜻하는지, 정리·만료·재시도 같은 기능 동작의 변경을 뜻하는지 독자가 다시 구별해야 한다. 짧은 PR에서 리뷰어가 ‘이번 변경이 관측 추가인가, 동작 변경인가’를 파악하는 데 불필요한 모호함이다.

### 원자료 근거

S03은 대기 항목 생성·제거·만료 콜백 진입의 진단 로그를 추가한 변경이다. S05는 정리 조건, 제한 시간, 재시도 처리, 응답 형식을 바꾸지 않았으며 관측용 변경이라고 한정한다. S07은 테스트를 수행하지 않았고 변경 후 진단 로그도 수집하지 못했다고 명시한다. 따라서 마지막 문장에서 미검증 대상을 원인 가설과 추가한 로그의 출력으로 특정할 수 있다. 기능 동작을 수정했다고 넓혀 읽을 여지를 둘 필요가 없다.

### 구체 수정안

마지막 문단을 다음과 같이 고친다.

> 로컬 합성 요청 환경이 없어 테스트와 변경 후 로그 수집을 못 했습니다. 원인 가설과 추가 로그의 출력도 검증하지 못했습니다.

새 사실이나 검증 결과를 추가하지 않는다. 원래 요청의 250~400자 분량 제한도 유지해야 한다.

### 수정 후 확인할 질문

1. 리뷰어가 변경 내용은 관측용 로그 추가이고, 기존 기능 동작은 그대로라는 점을 한 번에 구별할 수 있는가?
2. 원인 가설과 새 로그 출력 모두 아직 검증하지 않았다는 뜻이 명확한가?
3. 전체 PR 설명이 250~400자 정도의 원래 분량 요구를 지키는가?

## 수정하지 않아도 되는 부분

- **01 CLI README:** 첫 실행, 덮어쓰기, 오류 처리, 검증 환경과 지원 범위가 독자가 행동하는 위치에 충분히 제시되어 있다.
- **02 이벤트 아키텍처:** 접수와 저장, 클라이언트 재제출과 worker 재처리가 구별된다. 관련 경고의 재등장은 다른 책임 주체를 설명하는 문맥에 필요하므로 반복만을 이유로 삭제할 필요가 없다.
- **03 조사 PR:** 관측, 가설, 실제 변경, 검증 범위와 배포 후 계획을 구분하고 있다.
- **04 장애 대응 절차:** 진행 조건과 이관 조건을 행동 단계 및 마지막 표에서 함께 제공한다. 이 반복은 긴급 확인에 유용하다.
- **05 저장소 ADR:** 제안 상태와 미결 보존 정책, 거래 범위, 성능 미측정이 명확하다. 보존 정책이 여러 곳에 나타나더라도 각 문맥의 판단에 필요하다.
- **06 문단 수정:** 설정 범위, 커서 후속 조회, 버전별 확인 범위가 충분히 구체적이다.
- **07 색인 온보딩:** 중단 수락과 실제 종료, 완료와 검색 시작 시점, 재시도와 원본 선택을 구분한다. 긴 문서라 탐색 링크를 추가할 여지는 있으나 기존 제목과 배치만으로 실제 조건을 찾기 어렵다고 단정할 근거는 부족하다. 목차 부재 자체를 수정 필수 결함으로 분류하지 않는다.
- **09·10:** 원자료 대조 미완료이므로 사실 정확성에 대한 판정을 보류한다. 현재 본문만으로 교정을 확정할 만한 독자 장애를 찾지는 못했다.
