## 검토한 문서와 보존 범위

현행 안내에서 일회성 PID·포트·컨테이너 로그나 작업 세션 표현의 실제 잔존은 발견되지 않았습니다. 문서에서 안내하는 재사용 가능한 출력 경로는 실행 이력으로 오인해 옮기지 않았습니다. 원시 기록의 보존 여부와 코드 블록·식별자·수치·기존 앵커의 유지 여부를 기준 커밋과 대조합니다.

코드 블록·인라인 식별자·기존 제목·숫자 구성 요소와 새 이력 링크를 대조했고, 활성 교정 후보는 0건이었습니다. 다음 의미와 제한도 원문과 직접 대조했습니다.

- 이미 발급된 자격을 등록하는 동작을 새 자격 발급으로 바꾸지 않았습니다.
- 접근 권한으로 보호하는 경로를 암호화 저장소로 바꾸지 않았습니다.
- 파일 저장을 DB 저장으로 바꾸지 않았습니다.
- PID 존재를 워커의 정상 동작을 검증한 결과로 바꾸지 않았습니다.
- 외부 API 요청을 차단하는 동작과 계속 실행 중인 워커를 구분했습니다.
- 중복을 포함한 행 수를 고유 키 수로 바꾸지 않았습니다.
- 실행 정책으로 거부된 명령의 미실행 상태와 응답 미확인 상태를 유지했습니다.
- 워커 판정 대상 기록을 날짜가 있는 자격 등록 시도와 분리했습니다.

이번 적용은 문서 2개를 한 번 교정한 제한된 확인입니다. 기존 평가 문서 14개를 다시 생성하지 않았고, 이전 스킬과의 품질 비교나 사람의 독해 속도·선호도 측정도 실시하지 않았습니다.

## 보존 원문에 남아 있는 참조

[과거 검토 원문](../../evaluations/runs/2026-11-03-v0.4.0/reviews/review-core.md)의 인용문에는 다른 문서에서 복사한 내부 링크 1건이 있습니다. 복사된 검토 파일 안에는 대응하는 제목이 없어 그 위치에서는 이동할 수 없습니다. [인용한 원문의 해당 절](../../evaluations/runs/2026-11-03-v0.4.0/outputs/latest/01_cli_readme.md#입력-오류-처리)은 존재합니다.

이 파일은 수정 금지인 원본 사본이므로 링크를 덮어쓰지 않았습니다. 검사기는 검토 파일과 인용 원문이 고정된 해시와 일치하는지, 인용문과 원문 앵커가 실제로 존재하는지 확인한 뒤 이 1건을 별도로 보고합니다. 따라서 수정 가능한 문서의 깨진 참조가 없더라도 원시 사본까지 포함한 모든 링크가 정상이라고 표시하지 않습니다.

교정 사전의 탐지 예문과 과거 원문에는 교정 대상 표현이 의도적으로 남아 있습니다. 본문 위반의 잔존 수와 원시 문자열 검색 수를 구분하며, 정규식 검사나 예제 적용을 사람의 독해 속도·문장 선호도 측정으로 해석하지 않습니다.
