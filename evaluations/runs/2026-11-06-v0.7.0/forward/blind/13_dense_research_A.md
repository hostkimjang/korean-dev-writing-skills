# 느티나무 자료 가져오기 조사

다음 개발은 입력 정보 보존과 판정 경로 연결부터 진행할 것을 권합니다. 운영 shadow 실행에서는 입력 420행이 모두 보류됐고, 별도로 구성한 기준 40행에서도 현행 엔진은 모두 판정 불가였습니다. 모델과 증강 자료의 정확도 기여는 판정 경로를 연결한 뒤 독립 평가로 확인할 과제입니다.

## 1. 운영 입력 420행은 모두 보류됐습니다

2026-10-28 운영 작업함 3개에서 관측한 입력은 CSV 300행과 NDJSON 120행으로, 총 420행입니다. XML 입력은 없었습니다. 당일 운영 shadow 실행에서는 필수 정책 누락 45행과 파서 검토 필요 375행으로 입력 전체를 보류했으며, 저장 DB 반영은 0건이었습니다.

이전에 보고한 수용 12행은 연구 PC의 별도 개발 이미지에서 재생한 결과입니다. 운영 shadow 실행의 수용 결과에 포함하지 않습니다.

## 2. 기준 40행은 격리 환경에서 재현됐지만, 정확도 기여는 측정하지 않았습니다

2026-11-01 연구 PC와 시험 서버의 자료로 구성한 기준 40행에는 조치 필요 15행이 포함돼 있습니다. 현행 엔진은 40행 모두 판정 불가로 처리했고, 조치 필요 보고는 0행이었습니다. 이 기준은 운영 입력 420행과 다른 집단이므로 결과를 현장 결과로 옮겨 해석하지 않습니다.

기준 작성에 사용한 동일 원문과 규칙을 격리 환경의 어댑터에 넣으면 40행 모두 기준과 일치합니다. 다만 독립 평가셋으로 정확도 기여를 측정한 결과는 없습니다. 따라서 이 재현 결과를 정확도 개선으로 일반화할 수는 없습니다.

## 3. 문서 추출 비교에서 LLM이 추가로 맞힌 답은 없었습니다

문서 추출 비교는 구조화 12문항과 조건부 8문항을 대상으로 했습니다. 이 비교에서 LLM이 규칙보다 더 맞힌 답은 없었습니다.

## 4. 변환기 단독 지연은 측정했으며, GPU 반복 횟수는 자료에 없습니다

2026-11-02 bench-b에서 측정한 변환기 단독 지연은 다음과 같습니다.

| 실행 조건 | 반복 횟수 | p50 지연 | 최대 RSS |
| --- | --- | --- | --- |
| CPU 2스레드, 질의 1개씩 | 1,000회 | 31.2ms | 1.40GiB |
| GPU fp16 | 자료에 없음 | 3.8ms | 자료에 없음 |

이 수치는 변환기 단독 지연 측정값입니다. 정확도나 전체 작업 완료 시간을 나타내지 않습니다.

## 5. 재순위 평가에서 Pine-Reranker의 1순위 정답 건수가 더 많았습니다

같은 후보 풀을 사용한 600질의 재순위 평가에서는 정답을 공개 사전 대응으로 기계 생성했으며, 사람이 검수하지 않았습니다. 입력 유형별 1순위 정답 건수는 다음과 같습니다.

| 입력 유형 | 질의 수 | 어휘 검색의 1순위 정답 | Pine-Reranker의 1순위 정답 |
| --- | --- | --- | --- |
| 사전 제목 | 240질의 | 180건 | 195건 |
| 패키지명 | 360질의 | 244건 | 249건 |

통계적 동등성이나 유의성 검정은 수행하지 않았습니다. 이 평가는 사람이 검수하지 않은 기계 생성 정답을 사용했으며, 실제 운영 정확도를 확인한 결과는 아닙니다.

## 6. 운영 수집기는 하루 결과가 12,000건을 넘는 구간을 건너뜁니다

2026-11-03 수집기 점검에서 하루 결과가 12,000건을 넘으면 해당 구간을 건너뛰는 로직을 확인했습니다. 운영 수집기는 같은 로직으로 6시간마다 실행 중입니다.

점검 대상 18,240건 중 18,200건은 이전 판이었습니다. 무작위로 확인한 60건의 본문 구성은 같았습니다.

## 7. 새 수집기는 실패 이후 후속 실행 기록과 자동 재시도 장치가 확인되지 않았습니다

새 수집기는 2026-10-02 실패한 뒤 2026-10-29까지 9개 출처 모두 후속 실행 기록이 없습니다. 자동 재시도 장치도 확인되지 않았습니다.

## 다음 개발 순서

다음 순서로 개발을 진행할 것을 권합니다.

1. 입력 정보를 보존하고 판정 경로를 연결합니다.
2. 원천 자료와 증강 자료를 정리합니다.
3. 후보 검색과 소형 모델을 대조합니다.
4. LLM 보조 검토를 진행합니다.

이 순서는 개발 계획에 대한 제안이며 배포 완료를 뜻하지 않습니다. 운영 반영 일정은 미정입니다.
