# trace-slice

trace-slice는 로컬 JSON Lines 로그 파일에서 지정한 최소 심각도 이상의 항목을 골라 내는 CLI입니다. 로그에서 오류 항목을 찾을 때 사용할 수 있으며, 로그를 네트워크로 전송하지 않습니다.

이 README는 **0.4.2** 버전을 설명합니다.

## 설치와 첫 실행

프로젝트에서 선언한 Python 요구 버전은 **3.10 이상**입니다. 설치와 기본 동작을 확인한 환경은 **Ubuntu 22.04의 Python 3.11**이며, 다른 운영체제에서의 검증 기록은 없습니다.

1. 버전을 고정해 설치합니다.

   ```bash
   python -m pip install trace-slice==0.4.2
   ```

2. 도움말이 표시되는지 확인합니다.

   ```bash
   trace-slice --help
   ```

3. 로컬 로그 파일에서 오류 항목을 확인합니다. 아래의 `./logs/api.jsonl`은 예시 경로이므로, 읽을 수 있는 실제 로그 파일 경로로 바꿔 실행하세요. 입력은 JSON Lines 형식이며, 각 정상 로그 행에는 `level` 필드가 있습니다.

   ```bash
   trace-slice ./logs/api.jsonl --level error
   ```

   이 명령은 `error` 항목을 표준 출력으로 내보냅니다.

## 사용 방법과 주요 옵션

```text
trace-slice INPUT [--level LEVEL] [--output PATH]
```

`INPUT`은 필수 위치 인수입니다. `INPUT`, `LEVEL`, `PATH`는 각각 사용할 파일 경로, 심각도, 저장 경로로 바꾸세요.

| 인수·옵션 | 설명 | 생략했을 때 |
| --- | --- | --- |
| `INPUT` | 읽을 로컬 JSON Lines 파일의 경로 | 생략할 수 없음 |
| `--level LEVEL` | 출력할 항목의 최소 심각도. `debug`, `info`, `warn`, `error` 중 하나를 지정 | `info` |
| `--output PATH` | 결과를 저장할 파일 경로. **파일이 이미 있으면 덮어씀** | 표준 출력으로 내보냄 |

심각도는 `debug` → `info` → `warn` → `error` 순으로 높아집니다. `--level`로 지정한 값과 그보다 높은 심각도의 항목이 출력됩니다. 예를 들어 `--level warn`은 `warn`과 `error` 항목을 출력하며, 옵션을 생략하면 기본값인 `info`에 따라 `info`, `warn`, `error` 항목을 출력합니다.

결과를 파일에 저장하려면 `--output PATH`를 추가하세요. 기존 파일을 덮어쓰므로 실행 전에 저장 경로를 확인하세요.

## 입력 오류 처리

JSON 구문이 잘못된 행은 건너뛰고, 건너뛴 행 수를 표준 오류로 알립니다. 잘못된 JSON 행이 있다는 이유만으로 실행이 실패하지는 않습니다.

`INPUT` 파일을 읽을 수 없으면 오류를 표준 오류로 알리고 **종료 코드 2**로 끝납니다.

## 0.4.2의 제약

- 실행 중 늘어나는 로그를 계속 따라가는 기능은 없습니다.
- 날짜 범위를 지정하는 옵션은 없습니다.
