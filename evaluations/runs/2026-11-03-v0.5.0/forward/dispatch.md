# 원자료에서 새 문서 작성

동일 세션 계열의 새 컨텍스트 작성자에게 고정한 v0.5.0 스킬과 런북·짧은 PR·설정배포의 원래 입력만 전달했다. 기존 출력, 편집 완료 기준, 리뷰 내용은 전달하지 않았다. 입력의 독자·목적·요청·자료에 맞춰 문서를 쓰고 본문만 저장하도록 요청했다. 운영 명령을 실행하지 않도록 했다.

이 문서들은 교정 완료본 10개와 별도다. 작성자가 제출한 첫 결과를 `first/`에 보존하고, 확인 결과와 필요한 수정은 후속 기록으로 남긴다. 같은 원자료를 사용하므로 새로운 도메인에 대한 일반화나 사람 독자의 효과를 입증하는 실험으로 해석하지 않는다.
