## 실제로 바뀐 문장과 배치

### 롤백 명령 앞에서 기한과 정지 조건을 함께 확인

기존 롤백 절에는 두 정지 조건만 다시 나왔고, 5분 이관 기준은 앞 절에 있었습니다. 최종본은 일시정지 요청부터 롤백까지 한 절로 연결하고, 명령 앞에 다음 기준을 뒀습니다.

> 일시정지 요청 후 **5분이 지나도 두 조건을 모두 만족하지 못하면 롤백하지 않고 플랫폼 온콜에 이관합니다.** 처리 중인 작업을 강제로 종료하지 않습니다.

같은 절에서 두 조건이 `state=paused`와 `inflight=0`임을 확인합니다. 5분은 pause 요청부터 계산하며, 두 조건을 만족했다면 5분이 될 때까지 기다리라는 뜻으로 바꾸지 않았습니다. [런북 전문](examples/04_incident_runbook.md)

### 예약 충돌 응답 옆에 다음 행동을 명시

설정배포 안내의 `PENDING_RELEASE_EXISTS` 행에는 **대기 묶음 활성화 또는 예약 취소 후 재요청 가능**을 붙였습니다. 거절 원인을 찾은 자리에서 언제 다시 요청할 수 있는지 함께 읽습니다. 준비 단계에 입력 이름을 보완하고도 본문은 이전과 같은 1,783자입니다. [설정배포 안내 전문](examples/09_config_rollout.md)

### 짧은 PR은 분량 안에서 필요한 필드를 복원

로그를 켜는 조건 뒤에 `ticket_ref`, `elapsed_ms`, 남은 대기 항목 수와 요청 본문 제외 범위를 넣었습니다. 관측 출처, 원인 미확정, 로그만으로 실제 영향을 판단할 수 없는 이유, 환경 미준비로 검증하지 못한 이유도 남겼습니다. 본문은 공백 포함 399자이며 마지막 개행까지 세면 400자입니다. [짧은 PR 전문](examples/08_short_log_pr.md)

## 스킬에도 반영한 절차

설치용 [SKILL.md](../skills/korean-dev-writing/SKILL.md)와 참고 문서 세 개에 다음 규칙을 반영했습니다.

- 바로 찾아 실행할 명령에는 선행조건·시간의 시작 기준·실패와 중단 대응을 같은 실행 단위에 둡니다.
- 오류 응답에는 원자료에 있는 재요청 가능 시점과 해제 조건을 붙입니다.
- 표 뒤의 설명은 선택 이유나 해석을 보태며, 같은 행의 내용을 다시 길게 나열하지 않습니다.
- 여러 중단 사유는 AND/OR 의미를 유지하면서 조건별로 분리합니다.
- 짧은 글은 중복과 불필요한 형식을 먼저 줄여 대상·판단 근거·필요한 필드·검증 범위를 보존합니다.
- 작성·교정에서 발견한 문제는 본문에서 수정하고 영향을 받은 사실·실행 조건을 다시 확인합니다. 과거 원문을 남겨야 하면 별도 교정본까지 완성합니다.

## 완료 확인

편집자와 다른 컨텍스트의 검토자가 원자료·작성 요청·교정본을 대조했습니다. 기존 계약의 의미와 질문을 변경하지 않았고, 실제 최종 본문을 인용해 판정을 남겼습니다.

| 확인 대상 | 최종 판정 |
| --- | ---: |
| 원자료의 필수 의미 | 150개 모두 보존 |
| 독자의 탐색 질문 | 37개 모두 답변 가능 |
| 이번 편집 완료 기준 | 11개 모두 해결 |
| 검토에서 남은 수정 대상 | 0개 |

이 수는 확인한 기준의 개수이며 품질 총점이 아닙니다. 원자료나 검증 결과가 없는 사실은 새로 만들지 않았습니다. [완료 항목과 인용 근거](../evaluations/runs/2026-11-03-v0.5.0/repair-results.json), [의미·질문 검토](../evaluations/runs/2026-11-03-v0.5.0/reviews), [같은 입력과 해시](../evaluations/runs/2026-11-03-v0.5.0/manifest.json)에서 확인할 수 있습니다.

`check_repairs.py`는 미해결 판정·누락된 검토·일치하지 않는 인용과 해시가 있으면 통과하지 않습니다. 공개 예시가 검토한 최종본과 같은 바이트인지도 검사합니다. 의미와 자연스러움은 모델이 원자료와 대조한 판단이고, 자동 검사는 그 기록의 완전성과 파일 일치를 확인합니다.

## 기존 결과를 보지 않고 새로 작성한 확인

런북·짧은 PR·설정배포 안내 3개는 별도의 새 컨텍스트에서 원래 입력과 v0.5.0 스킬만 보고 작성했습니다. 기존 문서·수정 요청·검토 결과를 전달하지 않았습니다. 이 첫 결과도 다른 검토자가 원자료와 대조했습니다. [새 작성본과 검토 기록](../evaluations/runs/2026-11-03-v0.5.0/forward)에서 확인할 수 있습니다.

## 기록의 범위

현재 배포 예시는 기존 출력과 피드백을 보고 교정한 결과입니다. 편집자는 제출 전에 스스로 수정·확인했으며, 별도 검토에서는 추가 교정이 필요한 항목이 발견되지 않아 첫 제출본을 최종본으로 채택했습니다. 기존 원문과 첫 제출본은 각각 보존했습니다.

이번 확인은 공개용 가상 자료에 대한 모델의 원자료 대조와 정적 검사입니다. 사람의 읽기 시간·이해도·피로 감소를 측정한 수치로 설명하지 않습니다. [교정 프로토콜](../evaluations/runs/2026-11-03-v0.5.0/protocol.md)에 전달한 자료와 확인 절차를 기록했습니다.
